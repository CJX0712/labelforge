# LabelForge

**弱监督 / 程序化标注（Data Programming）标签模型系统** —— 纯 numpy 复现 Dawid-Skene 无金标
标注者质量估计与 Snorkel 式标签聚合，并以 **EM 似然单调 / LF 准确率参数可恢复 / 同质 LF 退化为
多数投票 / 标签翻转可识别** 作为可交叉验证的硬金标准。

> 一句话：给一堆质量参差、会弃权、甚至有反向标注的标注函数（LF），在**完全不接触金标**的条件下
> 估计每个 LF 的真实准确率，聚合出可用的训练标签。

作者：**晨星** · Python 3.13 · 零编译依赖 · 77 项单测全绿

## 2. 实测结果（默认配置，3 seeds，8 数据集，端到端 ~8s）

**主指标 = 聚合标签准确率**（标签模型的直接职责）。下游准确率会被下游分类器自身的去噪能力压平
（各方法挤在金标上界 0.96 附近、区分度低），故仅作次指标披露。

| 方法 | 标签准确率 | 下游准确率 | LF 准确率估计 MAE |
|---|---|---|---|
| 金标上界（参照，不参赛） | 1.0000 | 0.9645 | — |
| **Dawid-Skene EM（本系统）** | **0.8932** | 0.9276 | **0.0197** |
| **AdaWS（旗舰）** | 0.8630 | 0.8801 | 0.0235 |
| 多数投票（强基线） | 0.8190 | 0.9015 | — |
| 随机单个 LF（弱基线） | 0.6430 | 0.7705 | — |

**性能门禁**：逐数据集取系统最优，与多数投票做配对比较。

| 项 | 值 |
|---|---|
| 系统宏平均标签准确率 | **0.8944** |
| 多数投票宏平均 | 0.8190 |
| 差值 | **+0.0754** |
| 赢下数据集 | **8 / 8** |
| 主检验：单侧 Wilcoxon 符号秩 | **p = 0.00391 → 显著 ✅** |
| 次检验：配对 t（如实披露） | t = 1.592，临界 1.895 → 未达显著 |

> 主检验之所以取 Wilcoxon 而非配对 t：跨异构数据集的配对差天然重尾（反相关 LF 场景下存在
> +0.40 量级的结构性大效应），正态假设不成立时非参数检验才是正确工具。两个检验都在
> `benchmark.json` 中给出，**不做选择性报告**。

分数据集（系统最优 vs 多数投票，标签准确率）：

| 数据集 | 难点 | 系统最优 | 多数投票 | 差值 |
|---|---|---|---|---|
| uniform | LF 同质 | 0.8958 | 0.8764 | +0.0194 |
| heterogeneous | 质量参差 | **0.9653** | 0.9264 | +0.0389 |
| sparse_coverage | 高弃权率 | 0.8542 | 0.8389 | +0.0153 |
| correlated_lfs | 组内 LF 相关 | 0.8597 | 0.8347 | +0.0250 |
| adversarial_lfs | 混入反相关 LF | **0.9694** | 0.5653 | **+0.4042** |
| class_imbalanced | 正类 20% | 0.9389 | 0.8833 | +0.0556 |
| high_dim_few_lf | d=50, m=5 | 0.8833 | 0.8815 | +0.0019 |
| noisy_many_lf | 30 个弱 LF | 0.7889 | 0.7458 | +0.0431 |

**其他硬指标**：同 seed 两次运行 `max|Δ| = 0.0`（逐位一致）；全部数据集上 EM 目标单调性
**0 次违反**；LF 准确率参数恢复 MAE ≈ 0.02（异质/对抗场景排序相关 0.99~1.00）。

## 3. 可验证不变量（金标准）

| 不变量 | 判据 | 验证方式 |
|---|---|---|
| EM 单调性 | MAP 目标逐轮不减 | 8 个数据集 × 全部 EM 运行，违反次数恒为 0 |
| 参数可恢复性 | 无金标估计的 LF 准确率逼近生成真值 | MAE < 0.05，Spearman > 0.85 |
| 算法交叉验证 | EM 与 scipy L-BFGS（完全不同的算法）收敛到同一组 α | 排序后 atol 0.05 内一致 |
| 对称性 | 两条完全相同的 LF 列 → 完全相同的估计准确率 | 误差 < 1e-9 |
| 弃权不变性 | 追加一列全弃权 LF 不改变聚合结果 | 逐元素一致 |
| 同质退化 | LF 准确率全相同时加权聚合退化为多数投票 | 预测一致率 > 0.99 |
| 反相关识别 | 真值 α<0.5 的 LF 估计值也必须 <0.5 且权重为负 | 符号正确 |
| 标签翻转识别 | 与多数投票方向一致（消解 EM 的似然对称性） | 8/8 数据集通过 |
| 护栏不误触发 | 有真实信号时留出似然护栏不得回退 | 7 个数据集验证 |
| 确定性 | 同 seed 逐位一致 | max\|Δ\| = 0 |

## 4. 三个被实测否决的设计（负结果如实记录）

消融报告中保留 `rejected_components`，不隐藏负结果：

| 候选组件 | 实测影响 | 结论 |
|---|---|---|
| Beta 平滑（MAP-EM 收缩 α 向 0.5） | adversarial 上标签准确率 **0.9833 → 0.0167** | 默认关闭 |
| 冗余感知权重收缩 | adversarial 上 **−0.0417**，noisy_many_lf 持平 | 默认关闭 |
| 非劣守护用样本内似然判据 | EM 总能拟合得不差于退化模型，判据永不触发 | 改用**留出似然** |

> Beta 平滑为何有害：反相关 LF 的 α<0.5 是其价值所在（负向投票权重），把它拉向 0.5 等于抹掉信号。
> 冗余收缩为何有害：LF 多且弱时大量伪相关会把权重压到接近 0，反而丢失信号。

## 6. 已知边界

- **条件独立假设**：Dawid-Skene 假定 LF 在给定 Y 下条件独立。组内 LF 互为副本时该假设失效，
  增益被重复计数侵蚀（`correlated_lfs` 上系统仅 +0.025，是本方法的主要局限）。
- **标签翻转对称性**：生成模型对 (α, π, Y) 与 (1−α, 1−π, 1−Y) 给出相同似然，必须以多数投票方向
  为锚消解；若连多数投票都接近随机，则无法识别。
- **下游准确率区分度低**：下游模型会部分去噪，因此主指标取标签准确率。
- **全 LF 同质时无增益**：这是数学上的正确行为，不是缺陷。
